# Forecasting-Indian-Oil-Corporation-Stock-Prices-Using-ARIMA-and-SARIMA-A-Time-Series-Approach
Analyzed Indian Oil Corporation (IOC.NS) stock prices using time-series methods, including EDA, stationarity testing, ACF/PACF, ARIMA and SARIMA modeling, walk-forward validation, and a naïve benchmark. Evaluated forecasts with MAE/RMSE and residual diagnostics, then generated 30-step forecasts.
